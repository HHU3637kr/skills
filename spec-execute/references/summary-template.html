双向关联规则

  • 正向：本报告引用别人 → rk-links 加一条，data-rk-link 写关系类型。
  • 反向：别人引用本报告 → rk-backlinks 加一条，data-rk-backlink 写关系类型。
  • 谁新建关联谁负责补对侧；对侧报告尚未产出时先在列表里标注「（待创建）」，等对侧出现再补齐。

撰写要点

  • 结论块 rk-verdict 一句话说清实现结果；全部实现加 is-pass，有未实现项加 is-fail。
  • Callout 用 rk-cal key（关键决策）/ warn（注意）/ risk（风险）/ ok（通过）。
  • 代码位置一律 <span class="rk-ref">file:line</span>。
  • 修改已确认的总结时永不静默改写：修订号 +1（同步 rk:revision / rk:updated）、修订历史表追加一行、正文用 <ins class="rk-ins" data-rev="N"> / <del class="rk-del" data-rev="N"> / <p class="rk-added|rk-removed" data-rev="N"> 标记。详见 html-report skill。
  • 禁止写 <style>、行内 style= 或引用外部 CDN。
