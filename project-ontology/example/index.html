项目定位

TeachingAnalyzer 智能教研分析系统（本体示例）：从课堂音视频转写、多维结构化抽取到教学质量综合评分与离线报告导出的全链路管线

  • 上游依赖 ASR 转写产物（transcript_segments），下游统一消费标准化评分快照
  • 核心评分采用「规则确定性分 + LLM 语义分」混合加权，并在超时时降级回纯规则分
  • 部分缓存键历史遗留全局可变上下文，修改评分权重时必须同步回归导出看板

全景数据流

音视频接入与 ASR生成分段文本 transcript_segments
综合评分管线规则分 + LLM 语义分混合计算
共享评分上下文缓存旁路可变状态（Phase 4.5 关注）
↓输出标准化评估结果 score_total 与分项指标
报告渲染与看板展示综合教学质量分与离线 PDF/HTML
