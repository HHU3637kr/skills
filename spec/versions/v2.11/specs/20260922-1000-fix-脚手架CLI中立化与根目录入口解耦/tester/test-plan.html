1. 测试范围与原则

  • 不可手写证据：所有测试结果、标准输出、退出码均由测试脚本自动落盘至 tester/artifacts/test-logs/。
  • 新鲜验证（Fresh Verification）：必须在真实的临时隔离沙箱目录（/tmp/test-rk-scaffold-*）中运行实际的脚本文件。
  • 断言期望态（Expectation Assertions）：断言逻辑严格根据产品期望设计，不针对坏态写通过逻辑。
