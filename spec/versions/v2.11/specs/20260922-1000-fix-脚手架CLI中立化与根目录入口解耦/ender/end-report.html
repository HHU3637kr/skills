2. 经验反思与沉淀 (Experience Reflection)

架构经验：业务项目公共资产与开发者本地环境外挂必须彻底分层

困境：脚手架脚本若为了方便单一本机环境（如 OMP），把入口生成进私有隐藏目录（.omp/AGENTS.md），会导致业务代码库被单一开发工具绑架，使其他 Agent 和 CI/CD 流水线失效。
策略：任何 AI 开发规范必须将「项目公共规约」与「客户端本地外挂」严格物理隔离：根目录 AGENTS.md、.agents/rules/、.agents/roles/ 是团队唯一权威资产；而 .omp/、.claude/、.codex/ 属于个人开发环境，统一由 .gitignore 隔离。
