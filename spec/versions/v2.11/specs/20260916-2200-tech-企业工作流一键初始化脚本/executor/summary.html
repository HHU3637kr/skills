2. 核心技术实现细节

  • POSIX 与 Windows Git Bash 兼容：init-ai-workflow.sh 中加入了 CYGWIN*|MINGW*|MSYS* 探测，优先利用 cmd.exe /c mklink /J 建立 NTFS 目录联接，避免 Git Bash 下默认 ln -s 退化为深拷贝。
  • Windows 免提权技术：init-ai-workflow.ps1 采用 New-Item -ItemType Junction 技术，无需用户开启 Windows 开发者模式或使用管理员终端。
  • 全生命周期基础设施装配：从代码拉取、企业规则、薄入口、三级架构骨架、AWR 运行时挂载到 .gitignore 幂等追加一次性全自动闭环。
