1. 核心修复点实施清单

  1. 目标目录自愈 (Self-healing)：
    • scripts/init-ai-workflow.sh：解析绝对路径前先执行 mkdir -p "$TARGET_DIR"，规避未建目录 cd 报错。
    • scripts/init-ai-workflow.ps1：在 Resolve-Path 前判定 Test-Path，未建目录先调用 New-Item -ItemType Directory -Force。
  2. AWR 0.4.0 状态机兼容修补：
    • 移除 work-ledger.yaml 生成模板中的 goal: intake-goal，对齐标准 intake 单独组织任务规范，消除 [error] dangling_edge 报错。
  3. 普通物理目录安全备份保护：
    • Bash 脚本：检测到 .omp/skills 或 html-report 为普通物理目录时，自动重命名备份至 .bak-YYYYMMDD-HHMMSS 并提示，避免软链接产生内部嵌套。
    • PS1 脚本：New-JunctionSafely 检测到非 ReparsePoint 普通目录时，通过 Move-Item 重命名备份至 .bak-YYYYMMDD-HHMMSS，废除硬删除操作。
  4. 规则无覆盖保护：
    • PS1 脚本同步 .agents/rules 时逐项判断 -not (Test-Path $destFile)，不覆盖用户既有定制规则，对齐 Ubuntu cp -rn 语义。
  5. UTF-8 无 BOM 读写防退化闭环：
    • PS1 脚本使用 $Utf8NoBom = New-Object System.Text.UTF8Encoding($false) 写入所有文本与 .gitignore。
    • 读取 .gitignore 时显式声明 -Encoding UTF8，避免 PowerShell 5.1 在后续重跑时回退至系统 ANSI 代码页导致乱码。

2. 变更影响范围

  • scripts/init-ai-workflow.sh：增加目录自愈、普通目录安全备份，修复 AWR 模板。
  • scripts/init-ai-workflow.ps1：增加目录自愈、安全备份、规则防覆盖、UTF-8 无 BOM 读写闭环，修复 AWR 模板。
